# Simple Password Cracker

A very simple tool to crack passwords.

## Features

- Hash passwords using the MD5 algorithm.

- Crack MD5 hashes using a wordlist.

- Demonstrate password cracking with a sample hash.

## Requirements

- Python 3.x

## Installation

1. Clone this repository:

    ```sh
    git clone https://github.com/JotaRYT/Simple-Password-Cracked.git
    cd simple-password-cracked/src
    ```

2. Create a virtual environment:

    ```py
    python -m venv myenv
    source myenv/bin/activate  # On Windows: myenv\Scripts\activate
    ```

3. Install required packages:

    ```py
    pip install hashlib
    ```

    or

    ```py
    pip3 install hashli
    ```

## Usage

Run the script:

```bash
python3 s-p-c.py
```

## Security Notice

This tool should only be used for passwords/credentials you own or have explicit permission to test. Unauthorized password cracking may be illegal and unethical.
